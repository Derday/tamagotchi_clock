# Tamagotchi clock
Little project with Raspberry Pi Pico and 256x64 OLED display. Just basic clock that you need to take care of :).
## Casing
The whole thing is in little 3D printed box, printable with almost no support needed and easy assembly.
The design can be found on [onshape.com]("https://cad.onshape.com/documents/10b25d975da581af365d03cb/w/474f016589c233bc7f70a8c2/e/dc1b291e806c89f86a80a3a9")
